☁️ Cloud vs 🏢 On-Premise: Diferenças Técnicas N3

MODELO-CLOUD

ServiceDesk Cloud (SaaS)

Hospedado pela ManageEngine. Zero manutenção de infraestrutura, mas acesso limitado ao backend.

  • OAuth2: Único método para Mail Fetching.
  • ZSO Sync: Sincronização de usuários via 'Zoho Directory Sync'.
  • API-First: Customizações dependem 100% de Webhooks e REST API.
MODELO-PREM

ServiceDesk On-Premise

Controle total. Acesso direto ao banco PostgreSQL/MSSQL e arquivos de configuração.

  • Custom Scripts: Suporte a scripts Python/Batch locais.
  • AD Nativo: Integração direta via protocolo LDAP na rede interna.
  • DB Access: Possibilidade de queries diretas via PGAdmin.
