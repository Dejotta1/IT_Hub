Saúde do Cofre & Readiness (N3)

🔐 On-Premise: Segurança do Cofre

  • Encryption Key: Validar presença do arquivo p360_key.dat (sem ele, o PAM não inicia).
  • JVM Heap: PAM360 requer alto processamento para criptografia. Recomendado 8GB-16GB RAM.
  • Database Health: PostgreSQL local exige latência zero. Validar locks de arquivo pelo antivírus.
  • HA Cluster: Verificar se o nó Secundário está em 'Standby' e sincronizado.

🛰️ Connectivity: Remote Access

  • Gateway 7272: O túnel de sessão RDP/SSH exige a porta 7272 aberta para o mundo ou VPN.
  • SSL Trust: Se usar CA interna, o certificado deve estar no cacerts do Java do PAM.
  • Target Reach: Servidor PAM deve alcançar os alvos nas portas 3389, 22 e 445.
