Portas Necessárias
Liberar no firewall entre o servidor AD360/ADAudit e os alvos monitorados
PortaProtocoloDireçãoFinalidade
389 / 636TCP↔LDAP / LDAPS — comunicação com Active Directory
135TCP↔RPC Endpoint Mapper
445TCP↔SMB — admin share (\\server\admin$) e instalação de agentes
3268 / 3269TCP↔Global Catalog (LDAP / LDAPS)
8081TCP↔Comunicação Agente ADAudit Plus ↔ Servidor
8080 / 8443TCP→Console web ADManager Plus / ADSelfService Plus
443 / 8443TCP→ADSelfService Plus — Login Agent (GINA/MFA) ↔ Servidor
49152–65535TCP↔RPC dinâmico (WMI) — Remote Event Log Management
514UDP/TCP→Syslog para SIEM externo
⚠️ Para RPC dinâmico no Windows Firewall, habilitar as inbound rules: Remote Event Log Management (NP-In), Remote Event Log Management (RPC) e Remote Event Log Management (RPC-EPMAP).
