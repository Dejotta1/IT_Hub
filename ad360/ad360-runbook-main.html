2 procedimentos
BCK-101
Estratégia de Backup
Configuração e boas práticas para backup do banco de dados do AD360
  • Backup Manual: execute backupDB.bat em <AD360_Install_Dir>\bin
  • Automático: configure em Admin → General Settings → Database Settings
  • Agendamento diário de backup completo recomendado
  • Retenção mínima de 30 dias
  • Atenção ao limite de 10 GB do SQL Express
  • Armazenamento externo para backup crítico
⚠ CRÍTICOBACKUP
BCK-102
🔄 Procedimento de Recovery
Passos para restauração do banco de dados em caso de falha
1 Parar todos os serviços: net stop "ManageEngine AD360 *"
2 Restaurar banco via SQL Server → Restore Database ou pg_restore
3 Validar integridade: DBCC CHECKDB (SQL) ou pg_dumpall (PostgreSQL)
4 Iniciar serviços e validar: net start "ManageEngine AD360 *"
