Endpoint Central · Update Procedure

EC Update Checklist

Pré-lista de atualização do Endpoint Central. Siga os passos sequencialmente, marque cada item ao concluir e gere o comprovante ao final.

Progresso do Checklist
0 de 9 passos concluídos
🎉 Todos os passos concluídos! Preencha o formulário abaixo para gerar o comprovante.
PASSO 01
Validar Snapshot
Confirmar em ligação com o cliente se o snapshot da máquina foi realizado antes de iniciar o update.
⚠️
ALERTA: Não prossiga sem confirmar o snapshot com o cliente! Em caso de falha no update, o snapshot é a única forma de rollback.
Pendente
PASSO 02
Monitorar o Wrapper em Tempo Real
No PowerShell, navegue até a pasta de logs do Endpoint Central e execute o comando abaixo para monitorar o wrapper.log em tempo real. Mantenha esta janela aberta durante todo o processo. 
cd "C:\Program Files\ManageEngine\EndpointCentral\logs"
Get-Content -Path wrapper.log -Wait
Pendente
PASSO 03
Stopar o Serviço
Pare o serviço "ManageEngine Endpoint Central" antes de iniciar a atualização.
⚠️
ALERTA: Aguarde o serviço parar COMPLETAMENTE antes de continuar. Verifique no wrapper.log que o serviço foi encerrado.
Pendente
PASSO 04
Baixar o PPM da Versão
Acesse o site oficial da ManageEngine e baixe o arquivo PPM da versão que será aplicada. 
Link: https://www.manageengine.com/products/desktop-central/service-pack.html
Pendente
PASSO 05
Validar Arquivo Baixado
Verifique se o arquivo PPM baixado não está bloqueado pelo Windows antes de executar.
⚠️
ALERTA: Arquivo bloqueado causa falha no update! Clique com botão direito no arquivo > Propriedades > marque "Desbloquear" se a opção aparecer.
Pendente
PASSO 06
Executar initPgsql.bat
Execute o arquivo initPgsql.bat na pasta do Endpoint Central. 
cd "C:\Program Files\ManageEngine\EndpointCentral"
.\initPgsql.bat
Pendente
PASSO 07
Executar UpdateManager.bat
Execute o arquivo UpdateManager.bat na pasta do Endpoint Central para abrir a tela de atualização. 
cd "C:\Program Files\ManageEngine\EndpointCentral"
.\UpdateManager.bat
⚠️
ALERTA: Não feche o UpdateManager durante o processo de atualização! Isso pode corromper a instalação.
Pendente
PASSO 08
Adicionar o Arquivo PPM
Na tela do UpdateManager, clique em "Browse", navegue até o arquivo PPM baixado no Passo 4 e selecione-o para iniciar a atualização.
Pendente
PASSO 09
Subir Serviços e Validar
Após a conclusão do update, suba o serviço "ManageEngine Endpoint Central" e valide a ferramenta.
⚠️
ALERTA: Valide os itens abaixo antes de encerrar o chamado!
Sub-checklist de Validação:
Console acessível via navegador
Versão atualizada confirmada em Admin > About
Agentes comunicando normalmente
Nenhum erro crítico no wrapper.log
Cliente confirmou que está tudo ok
Pendente
